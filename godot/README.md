# 帝国：四线战令 · Godot 2.1

这是完整迁移到 Godot 4.7.2 / GDScript 的二维战术卡牌版本，包含单人训练、双人 IP 直连、开局换牌、公共与专属槽、拖动部署、指令箭头、卡牌音画反馈、单位技能、图鉴、组牌和设置。26 张卡牌沿用德系外形、日系二次元绘画风格的完整插画。

## Windows 开始游戏

解压 `EmpireFrontGodot-Windows-v2.1.zip`，双击 `EmpireFrontGodot.exe`。Windows 64 位发行版已将游戏资源嵌入 EXE，玩家无需安装 Python 或 Godot。保留同包的说明与许可证文件即可。

点击“单人练习”即可与训练指挥官对战；点击联机入口创建或加入双人房间。双方应使用同一 2.1 版游戏；2.1 不接受 Godot 2.0 或旧 Python 1.2 版连接。

2.1 保留迅捷基础 2 次行动、其他单位基础 1 次行动；加入双方共处、后方专属槽、单线箭雨和统一音画反馈。当前验证范围见完整仓库的 `docs/context/NOW.md`，历史报告不能证明新包已通过。

## 双人 IP 直连

1. 主机填写指挥官名称、端口和可选房间口令，创建房间。默认 TCP 端口为 **47653**。
2. 另一位玩家填写主机可达的 IP 地址、相同端口和口令，加入房间。两台电脑局域网联机使用主机的局域网 IP；`127.0.0.1` 只用于同一电脑测试。
3. 双方点击准备后进入换牌，确认换牌后开战。主机维护权威游戏状态。

连接要求双方能够通过该 IP 和 TCP 端口互通；本程序不会自动配置防火墙或路由器。连接中断时保留席位并暂停战斗，界面提供连接状态和重试。返回菜单会离开房间。

## 作战操作

- **换牌**：双方各获得 4 张初始手牌，点击任意牌可标记或取消替换，然后点击确认。点击“全部保留”直接确认保留。替代牌先从原牌堆抽取，旧牌随后放回洗牌。
- **四条战线**：画面从上到下依次为敌方后方、敌方前线、己方前线、己方后方；双方视角自动翻转。每线中间5个公共槽允许敌我共处，两条后方线各有2个对应基地守方独占槽。
- **部署与法术**：手牌随从仍只能在己方后方的可用槽部署，敌军存在不阻挡。拖到空槽可指定位置，点战线自动优先使用本方专属槽，再用公共槽。单体法术拖向单位或基地，战线法术拖向战线；箭雨只打选定线敌军，不能空放。非法操作不消耗手牌、召唤点或行动。
- **移动与攻击**：按住己方单位拉出指令箭头，原卡保持原位；指向合法敌军或基地为攻击，指向相邻战线合法空槽为蓝色移动。松开执行，也可点击选中再点目标。移动消耗1行动，不能跳线，建筑不能移动；单位死亡后其他单位不自动挤排。
- **单位状态**：卡面显示攻击、生命、防御和剩余行动。普通单位每回合基础 1 行动，迅捷单位基础 2 行动；没有突袭的单位通常部署当回合不能行动。
- **射程与防御**：近战射程 1，远程 2，超远程 3。攻基地不再要求清空敌军，仍需满足射程、飞行与敌方后方嘲讽限制。防御抵扣伤害，装弹单位攻击后需要等待；飞行和对空等特殊规则以图鉴卡牌说明为准。
- **技能**：点击己方单位，再使用右侧技能按钮。战线技能随后点击目标战线；调度依次选择友军和敌人；坦克工厂可选择制造轻型或中型坦克。技能按卡牌规则消耗行动、召唤点或冷却。
- **取消与回合**：按 Esc 或鼠标右键取消选择或拖动。点击右侧“结束回合”交给对手。基地初始 30 生命，归零即败；牌库耗尽后的抽牌会造成递增疲劳伤害。

点击卡牌可查看右侧完整说明；拖动时会提示合法目标。双方召唤点上限随各自回合增长，最高 10 点。

## 图鉴、牌组与设置

图鉴展示全部 26 张卡牌及插画。使用加减按钮组牌：牌组必须恰好 **30 张**，同名卡牌最多 **2 张**；不完整牌组不能保存，也可恢复默认牌组。

设置包含名称、卡牌动画、操作音效和全屏；F11 切换全屏。敌我成功部署、攻击、技能及公开结算使用相同的音画反馈，重连不重放历史效果；音效和动画可分别关闭。名称、IP、端口、开关与牌组写入 Godot `user://settings.json`，通常位于 `%APPDATA%/Godot/app_userdata/帝国：四线战令/settings.json`。**房间口令不保存到设置文件**。首次运行若没有 Godot 设置，可读取旧版 `.empire_front/settings.json` 中兼容的配置；两个版本的游戏规则和联机状态仍各自独立。

## 源码与构建

`EmpireFrontGodot-Source-v2.1.zip` 提供 `godot/` 项目、规则与联机测试、构建脚本及参考文档，不含庞大的 Godot 运行库、下载模板或 `.godot` 导入缓存。安装 Godot 4.7.2 后可直接导入 `godot/project.godot`；项目会重新导入插画。

从源码包根目录运行（开发构建需要 Python，玩家运行 EXE 不需要）：

```powershell
python tools/build_godot_release.py --godot "C:/你的路径/Godot_v4.7.2-stable_win64_console.exe" --build-only
```

脚本从官方模板包使用 HTTP Range 按需获取两个 Windows 模板，验证 CRC 与长度后保存在 `tools/godot-runtime/templates/`；已验证模板可离线重用。`--package` 或默认模式构建后生成独立 Windows 包与源码包；`--package-only --exe <已验证EXE路径>` 只整理已验证的 EXE，不重新导出。

2026-10-10 的历史复验记录规则、TCP、UI 及 Windows 导出 EXE 检查通过，详细结果与原始输出入口见 [代码审查与测试](docs/代码审查与测试.md#最终测试)。这些结果仅证明当时覆盖的场景，不代表后续修改或所有硬件与网络环境都已验证。
