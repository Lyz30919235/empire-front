# 第三方组件与素材说明

本 Windows 发行使用 **Godot Engine 4.7.2-stable** 官方 Windows x86_64 导出模板。Godot Engine 采用 MIT / Expat 许可；引擎与其所含第三方库的版权及完整许可文本随包保留：

- `licenses/GODOT-LICENSE.txt`：[Godot 4.7.2 官方 LICENSE.txt](https://github.com/godotengine/godot/blob/4.7.2-stable/LICENSE.txt)。
- `licenses/GODOT-COPYRIGHT.txt`：[Godot 4.7.2 官方 COPYRIGHT.txt](https://github.com/godotengine/godot/blob/4.7.2-stable/COPYRIGHT.txt)，包含引擎第三方组件版权与许可信息。

上述两个文件从对应官方发布标签原样取得。它们适用于 Godot 引擎及列明的组件，不自动授予本游戏代码或插画同样的许可。

卡牌插画沿用本项目的 26 张德系外形、日系二次元绘画风格资源；本次迁移没有另行下载或替换外部插画。项目未在此为游戏源码或美术新增公开授权条款。

中文文字通过 Godot `SystemFont` 请求 Microsoft YaHei、Noto Sans CJK SC、SimHei 及系统回退字体，使用玩家设备上已有字体。发行包不包含 Windows 专有字体文件。音效由游戏代码生成，不包含另行下载的外部音频素材。

源码包中的 `tools/skill-references/` 为开发参考文本，不参与游戏运行；各文件注明的来源与适用说明保留在原文中。
