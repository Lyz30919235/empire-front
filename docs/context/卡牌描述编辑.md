# 卡牌描述编辑

这是一份可直接修改并发回的卡牌调整需求文档。后续卡牌调整需求统一维护在本文件，避免同时维护多份互相冲突的新版说明。

## 如何填写与覆盖

1. 修改对应卡牌的名称、数值、关键词或描述；不需要调整的卡牌保留原内容。用途定位和补充规则可以使用自然语言填写；各种技能的详细效果在“技能说明编辑区”统一修改。
2. 卡牌标识用于匹配现有卡牌，请保留。改名只改“名称”；增加卡牌时写明“新增”及唯一标识，删除卡牌时明确注明“删除”，不要靠删掉章节表示删除。
3. 每次发回修改后的完整文档，以你最新提供的版本覆盖本文件的旧内容，不把旧版描述自动合并回来。未列出的卡牌不推断为删除，缺失且影响实现的信息标为“待核实”。
4. 描述尽量写清触发时机、作用目标、效果数值、持续时间、消耗、冷却和次数限制。不需要的限制写“无”，保留原规则写“保持原规则”；删除原有效果时明确写明。
5. “用途定位”表达你希望它发挥的作用，“卡牌描述”和“补充规则”表达具体要求。有矛盾或不足以实现的内容先核对，不擅自补全为已确认规则。
6. 新版文档覆盖后作为最新调整依据；是否已修改游戏数据、实现效果、测试或重新打包，分别记录在 [NOW.md](NOW.md)。文档保存成功不等于游戏效果已生效。

## 技能说明编辑区

以下说明按 2026-10-10 当前卡牌数据、引擎及相关界面定向核对填入，作为可修改的初始需求。可直接改写说明、消耗和限制；它们尚未经过本轮游戏运行验证。共用关键词的修改适用于所有带该关键词的卡牌；单张卡牌的例外在该卡的补充规则中注明。卡牌描述是展示摘要，与技能说明冲突时先核对，不自动选择一方。

说明来源：[engine.gd](../../godot/scripts/engine.gd) 的召唤、伤害、攻击、回合开始、打出卡牌、主动技能与死亡结算函数；技能操作核对 [main.gd](../../godot/scripts/main.gd) 的技能选择与制造入口。更新需求文档不代表这些实现已同步。

### 共用关键词与触发方式

普通单位每个自己的回合开始时恢复为基础 1 次行动，迅捷单位为基础 2 次行动，移动或普通攻击各消耗 1 次。无突袭的单位部署当回合行动为 0；技能通常也消耗行动。增益若未注明结束时间，下面明确说明其当前是否持续。

用户确认（2026-10-10）：所有迅捷单位基础行动统一为 2，其他单位为 1。号令获得迅捷、帝皇及战旗额外增加行动仍按下文规则结算；技能行动消耗不因此自动降低，空袭仍消耗 2 次行动。

|---|---|

|<a id="kw-ranged"></a>远程|普通攻击可选择战线距离不超过 2 的敌方单位，也可攻击飞行单位；不自动获得远距离反击。攻击基地仍受基地距离和后方嘲讽限制，不再要求清空敌军。|
|<a id="kw-long-range"></a>超远程|普通攻击可选择战线距离不超过 3 的敌方单位，也可攻击飞行单位；四条战线中的所有单位均在最大射程内。攻击基地仍需符合基地攻击条件。|
|<a id="kw-retaliation"></a>反击|受到单位普通攻击时，若符合自身射程、目标类型且未装弹，可反击；反击不消耗行动，也不要求有剩余行动。普通单位在距离不超过 1 时也可合法反击，此关键词增加远距离反击能力。法术和直接技能伤害不触发反击。|
|<a id="kw-assault"></a>突袭|部署当回合立即获得 1 次行动；同时具有迅捷时获得 2 次，可用于移动、攻击或满足条件的技能。|
|<a id="kw-swift"></a>迅捷|自己的回合开始时基础行动由 1 增至 2；单独拥有迅捷不会解除部署休眠或装弹限制。重复获得迅捷不再次增加基础行动。|
|<a id="kw-taunt"></a>嘲讽|选择某条战线的敌方单位进行普通攻击时，须先攻击该线上具有嘲讽的单位。敌方最后方战线的嘲讽也保护基地，包括阻挡飞行单位直击基地。不强制改变法术或直接伤害技能的目标。|
|<a id="kw-reload"></a>装弹|完成主动普通攻击后，本回合剩余行动清零；下个自己的回合不能移动、攻击、反击或使用主动技能，再下个自己的回合恢复。作为被攻击方反击不会额外触发装弹。|
|<a id="kw-flying"></a>飞行|普通地面近战单位无法攻击它；飞行、远程、超远程或对空单位可合法攻击它。飞行单位可绕过敌方场上单位直接攻击基地且不受基地距离限制，但敌方后方嘲讽仍阻挡。飞行不是完全免疫反击。|
|<a id="kw-air-only"></a>仅对空|普通攻击只能选择飞行单位或敌方基地，不能选择地面单位；攻击飞行单位仍受自身射程和嘲讽限制。|
|<a id="kw-anti-air"></a>对空|允许普通攻击飞行单位；本关键词本身不增加伤害或射程。高射炮的攻击强化和对飞行穿透是另列的专属效果。|
|<a id="kw-building"></a>建筑|不能移动或普通攻击；可按自身条件使用主动技能。占用战线位置，仍受生命、伤害和部署休眠规则约束。|
|<a id="trigger-battlecry"></a>战吼|从手牌打出对应单位并成功部署后自动触发，不额外消耗行动；技能制造或其他效果召唤单位不自动触发其战吼。具体效果按对应卡牌的说明。|
|<a id="trigger-death"></a>遗言|单位死亡并移出战场后自动结算，不消耗行动。先同时移出本次死亡单位，再处理遗言；衍生猎犬明确不继续触发遗言。|
|<a id="trigger-turn"></a>回合开始|在效果所属玩家自己的回合开始时自动结算，不消耗行动。当前先恢复行动并处理自愈及敢死队到期，再处理帝皇遗命、帝皇强化和战旗增益；改变顺序时请明确写出。|

### 主动技能

共同条件：轮到己方、单位在场且有足够行动，不处于装弹状态，技能不在冷却且未超过次数限制。无突袭单位部署当回合通常不能发动技能。对敌方单位造成的直接伤害受防御减免，不触发普通攻击反击。

<a id="skill-charge"></a>

#### 冲锋｜帝国重骑兵

- 效果：选择一条战线，对该线上每个敌方单位分别造成 2 点伤害；不伤害友军或基地。
- 消耗：1 次行动；无额外召唤点消耗。
- 冷却：使用后接下来的两个自己的回合不能再次使用，第三个自己的回合开始恢复。
- 次数与目标限制：无额外每局次数限制；可选择任一战线，不按普通攻击射程判断；空战线没有伤害收益。

<a id="skill-rally"></a>

#### 号令｜帝国冲锋手

- 效果：同线其他友军攻击 +1，并获得迅捷；不强化发动者。
- 消耗：1 次行动；无额外召唤点消耗。
- 冷却与次数：无冷却，每个冲锋手单位每局只能使用一次。
- 持续及行动细节：攻击提升和获得的迅捷持续保留；原本没有迅捷且当前仍有行动的目标立即增加 1 次行动。原本已具有迅捷的不额外加行动；行动为 0 的目标不因此解除部署休眠、装弹或重新获得行动。

<a id="skill-airstrike"></a>

#### 空袭｜帝国航空母舰

- 效果：选择一条战线，对该线上每个敌方单位分别造成 8 点伤害；不是整条战线总共分摊 8 点，不伤害友军或基地。
- 消耗：2 次行动；无额外召唤点消耗。
- 冷却：使用后接下来的两个自己的回合不能再次使用，第三个自己的回合开始恢复。
- 次数与目标限制：无额外每局次数限制；可选择任一战线，不按普通攻击射程判断。

<a id="skill-repair"></a>

#### 自修｜帝国中型坦克

- 效果：自身恢复 1 点生命，不超过生命上限。
- 消耗：1 次行动；无额外召唤点消耗。
- 冷却与次数：无冷却，无额外每回合次数限制；剩余行动允许时可重复使用。
- 目标限制：只能修复自身。当前实现允许满生命时使用并消耗行动；若希望禁止，请改写本条。

<a id="skill-manufacture"></a>

#### 制造｜帝国坦克工厂

- 效果：选择制造一辆帝国轻型坦克或帝国中型坦克，进入己方最后方战线；新坦克没有突袭，生成当回合处于部署休眠。
- 消耗：工厂 1 次行动，另支付 2 点召唤点制造轻型坦克，或 3 点制造中型坦克。
- 冷却与次数：无冷却，每个工厂每个自己的回合限一次；两种坦克共用该次数。
- 位置与条件：己方最后方战线须有本方可用空槽，敌军存在不阻挡。当前界面与实现限制的是坦克产出位置，未要求工厂自身必须停留在最后方战线。
- 操作：点选工厂，使用轻型或中型坦克制造按钮。

<a id="skill-command"></a>

#### 调度｜帝国决策塔

- 效果：选择另一名友军，再选择其合法的敌方单位或基地目标，立即执行一次普通攻击。
- 消耗：决策塔 1 次行动；被调度友军不消耗行动，无额外召唤点消耗。
- 冷却与次数：无冷却，每个决策塔每个自己的回合限一次。
- 目标与交互：友军可位于任一战线，即使剩余行动为 0 也可被调度，包括尚无行动的部署单位；但不能正在装弹，且须符合射程、目标类型、嘲讽、基地攻击等条件。不能调度塔自身、建筑或零攻击单位。
- 结算：这是普通攻击，会发生合法反击，也会触发敢死队首次攻击翻倍或攻击者装弹；不消耗友军行动不等于忽略其他攻击规则。

### 法术效果

使用法术支付该卡召唤点费用，不消耗场上单位行动；合法目标与效果如下。目标法术、范围法术和直接伤害技能不依赖单位普通攻击的射程或嘲讽要求。

|法术|可编辑说明|
|---|---|
|<a id="spell-loan"></a>借贷|本回合立即获得 2 点临时可用召唤点；下个自己的回合开始时扣除 2 点可用召唤点，最低为 0，召唤点上限不因此降低。多张借贷的债务会累加。|
|<a id="spell-arrows"></a>箭雨|选择一条有敌方随从的战线，对该线上每个敌方随从分别造成 2 点伤害，受各自防御减免；不伤害同线友军或基地，不触发反击，禁止空放。召唤点费用仍为4。|
|<a id="spell-fireball"></a>火球术|选择一个敌方单位造成 6 点伤害，受防御减免；不能选择基地，不触发反击。|
|<a id="spell-banner"></a>帝国战旗|选择一条战线，在接下来的 3 个自己的回合开始时，该线当时在场的友军攻击 +2，仍有行动的友军行动 +1。攻击提升会累积且不会在第 3 次触发后撤回；额外行动仅属于当回合。不会立即强化，也不会强化不在该线的单位。多面战旗可叠加。|
|<a id="spell-heal"></a>急救|选择一个友方单位或己方基地恢复 3 点生命；单位不超过自身生命上限，基地不超过 30。不能复活死亡单位。|
