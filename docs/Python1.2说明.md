# 帝国：四线战令

根据三张手写规则图片制作的Python双人战术卡牌游戏。1.2版采用KARDS式地图桌面、四条线性战线和拖动操作，保留26种卡牌、主动技能和遗言；支持开局任意数量换牌、单机训练、组牌、局域网与Radmin VPN双人对战。

## 运行

Windows版解压 `release/帝国四线战令-Windows.zip`，双击 `EmpireFront.exe`，不需要安装Python。桌面“帝国四线战令”快捷方式指向工作区的新版EXE。请把完整Windows压缩包发送给朋友，双方使用同一版本。

源码运行需要Python 3.10或更新版本，安装时包含Tcl/Tk。先运行 `python -m pip install -r requirements.txt`，然后双击 `启动游戏.bat` 或运行 `python main.py`。设置保存在用户目录 `.empire_front/settings.json`；异常记录在同目录 `error.log`。

## 对战操作

- 基地初始30生命，对方生命归零即胜利。
- 初始各4张牌，点击任意数量标记替换，然后确认；也可保留全部。新牌先从原牌堆随机抽取，旧牌随后返还并洗牌。每人开局只确认一次，双方确认后开战。
- 四条战线从上到下为敌方后方、敌方前线、己方前线、己方后方；对方看到镜像视角，己方后方始终在底部。
- **拖动手牌到最下方的己方后方部署。** 同一条战线只能由一方控制，最多3个单位。普通单位部署当回合休眠，突袭例外。
- **拖动友军到相邻空战线移动，逐线推进。** 每次移动消耗1行动，不能跨线，不能进入有敌军的战线；建筑不能移动。
- **拖动友军到敌军或敌方基地攻击；拖动法术到合法目标施放。** 黄色虚线标出合法落点，非法落点不扣资源；拖出战场、右键或Esc取消。
- 普通单位每回合2行动，迅捷3行动；攻击消耗1行动。召唤点上限每回合增加1，最高10。
- 近战射程1条战线，远程2条，超远程3条。地面攻击基地须清空敌军且基地在射程内，敌基地位于敌方后方外一格；近战需推进到敌方后方。飞行可直接攻击基地，但敌方后方的嘲讽仍保护基地。
- 点击单位可使用右侧技能按钮。工厂选择轻/中坦后点己方后方；决策塔选技能、友军，再选攻击目标。航空母舰衍生战机优先填后方，再填紧邻前线；敌占或满员时不生成。
- 悬停查看卡牌详细效果。主菜单“卡牌图鉴 / 组牌”可编辑30张牌组，同名最多2张。

## Radmin VPN 双人联机

1. 两人启动Radmin VPN，进入同一个VPN网络，确认彼此在线。
2. 房主填写名称、端口（默认 **47653**）和可选口令，点击“创建房间”。
3. 对方填写**房主在Radmin VPN中显示的IPv4地址**、相同端口和口令，点击“加入房间”。不要输入自己的IP。
4. 双方点击“准备开战”，各自完成换牌后开始。一次支持两人，房主先手。
5. Windows提示网络访问时，允许游戏通过VPN对应网络的防火墙。房主需要该端口的TCP入站权限；无需关闭整个防火墙。
6. 房主保持游戏和VPN运行。断线会暂停对局并自动重连，失败后在原窗口点击“重试连接”。关闭原窗口会丢失本次席位凭证；房主关闭后不能恢复房间。

程序绑定所有IPv4网卡，支持LAN或Radmin VPN虚拟地址，不需要Radmin Server。连接失败时核对VPN在线、房主IP、端口、口令、防火墙和房主是否还在房间中。熟人VPN房间采用TCP连接，无传输加密或互联网匹配服务。

同机验证：开两个窗口，第一个建房，第二个加入 `127.0.0.1`。已验证本机真实TCP双端，跨两台电脑的Radmin VPN对战仍需双方网络环境验证。

## 插画与规则来源

每种卡牌各有对应插画，采用**德系服装与机械外形、日系二次元绘画**，按名称和效果逐张设计，实际显示在起手、手牌、单位、详情和图鉴中。运行无需下载素材。使用内置ImageGen，提示词见 `assets/art-direction.json`，逐张记录见 `assets/generation/`。

用户舍弃的旧插画在 `archive/discarded-anime-20261008/` 归档，不随新版打包。没有使用炉石传说或KARDS的原始卡面、角色和音效。

原手稿抄录、模糊处和采用值见 [图片文字与规则.md](图片文字与规则.md)；后续确认的换牌、线性战线与部署规则优先采用。

## 源码与验证

`empire_front/cards.py` 为卡牌定义；`engine.py` 为权威规则引擎；`network.py` 为TCP房间与重连；`app.py` 和 `tabletop.py` 为桌面与拖拽界面；`assets/cards/` 为26张插画。

```powershell
python -m unittest discover -v
python tools/gui_smoke.py
```

测试覆盖80局完整AI对战、战线控制、后方部署、基地射程、非法操作资源不变、卡牌效果、换牌数量守恒、隐藏信息、TCP同步、掉线重连及再战。GUI测试使用本应用窗口的真实Canvas鼠标事件验证拖动、取消、双方视角与三种窗口尺寸。

打包（安装PyInstaller后）：

```powershell
python -m pip install pyinstaller
python tools/build_release.py
```

打包会将全部素材放入EXE，并运行EXE自身的Tk、26张插画、开局换牌、线性战线、拖动部署与TCP自检。版本1.2与旧版不能联机。
