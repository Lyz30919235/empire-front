# 帝国：四线战令

根据三张手写设计图片制作的 Python 双人战术卡牌游戏。当前 **1.1 开发版源码**采用KARDS式的复古地图桌面、纸质卡面与二次元插画；26种卡牌目前已提供5张独立插画，其余使用程序绘制的剪影。保留四条战线、主动技能和遗言，新增开局自由换牌；支持单机训练、卡牌图鉴、自定义30张牌组、LAN / Radmin VPN双人对战。

**当前发布状态：** 46项测试中45项通过，插画完整性检查因缺21张插画而失败。现有Windows下载包为早于当前源码的历史版本，不包含新版插画和开局换牌。完整状态与下载包区别见 [发布说明.md](发布说明.md)。

## 直接开始

历史Windows版：在仓库的 **Releases** 下载 **帝国四线战令-Windows.zip**，解压后双击里面的 **EmpireFront.exe**。不需要安装Python。该历史包与当前1.1开发版源码功能不同。请发送完整压缩包给朋友，双方使用相同版本。

源码版：Windows上安装Python 3.10或更新版本（勾选Tcl/Tk与添加PATH），双击 `启动游戏.bat`，或运行：

```powershell
python main.py
```

源码运行前安装插画显示依赖：`python -m pip install -r requirements.txt`。历史Windows版无需另外安装依赖；当前源码中的5张插画随源码一起提供。设置和牌组保存在用户目录 `.empire_front/settings.json`；异常记录在同目录的 `error.log`。

## Radmin VPN 双人对战

1. 两人安装并启动Radmin VPN，在软件中进入同一个VPN网络，确认彼此在线。
2. 房主打开游戏，填写名称、端口（默认 **47653**），可设置房间口令，点击**创建房间**。
3. 朋友在自己的游戏中填写**房主在Radmin VPN中显示的IPv4地址**，相同端口和口令，点击**加入房间**。例如显示26开头的地址时，应输入那个地址，不能用自己的IP。
4. 双方点击**准备开战**，各获得4张初始卡牌。点击想替换的任意卡牌，再点**确认换牌**；也可点击**保留全部**。双方确认后开始战役，房主先手；一次仅支持两人。
5. 若Windows提示防火墙访问，请允许游戏在Radmin VPN适配器对应网络上通信。房主需要允许该游戏程序的 **TCP 47653入站**；修改默认端口时对应更改。不需要关闭整个防火墙。
6. 保持房主游戏和VPN运行。断线暂停并自动重连；自动重连停止后，在原游戏窗口点击**重试连接**或**撤退 / 重连**。不要关闭原窗口，否则丢失本次席位的重连凭证。房主关闭后不能恢复房间。

程序绑定所有IPv4网卡，因此局域网IP和Radmin VPN虚拟IP均可使用。无需Radmin Server，不需要远程控制桌面。

Radmin VPN网络和防火墙排查参考：[Radmin VPN官方帮助](https://www.radmin-vpn.com/cn/help/)。官方说明建议游戏与VPN都能通过防火墙。本项目只使用TCP游戏连接。

**同机测试：** 开两个游戏窗口，第一个创建房间，第二个加入 `127.0.0.1`，端口相同。两台实体电脑和Radmin VPN真实跨设备连接仍需在你与朋友的网络中验证。

连接失败时检查：双方VPN网络一致、VPN显示在线、房主IP正确、端口及口令相同、房主仍在房间中、Windows或其他防火墙允许游戏TCP连接。端口占用会提示错误，可换47654等端口并让双方保持一致。

## 怎么玩

- 对方基地生命归零即胜利；基地初始30生命。
- 双方起手各4张，均可自由选择任意数量换牌，且每人开局只能确认一次。新牌先从原牌堆随机抽取，再返还旧牌并洗牌；旧的实体牌不会在本次替换中立刻抽回，但可能抽到牌堆中另一张同名牌。双方确认后先手首回合不额外抽牌，后续回合正常抽牌。
- 点击手牌，再点击战线部署。法术按提示点单位、战线或己方基地；无目标法术点击即使用。
- 点击友方单位，再点击敌军攻击。右侧可切换**移动**或**技能**。右键或Esc取消选择。
- 每条战线每人最多3个单位。普通单位部署后的下个自己的回合才能行动；突袭可立刻行动。
- 普通单位每回合2行动，迅捷3行动。移动与攻击各花1行动。每回合召唤点上限增加1，最高10。
- 近战攻击同线或相邻线；远程相距2线；超远程覆盖四条线。先清除敌军才能打基地，飞行有例外。
- 工厂选轻坦/中坦后点击战线；决策塔选技能、选友军、再选敌方攻击目标。
- 悬停卡牌查看详细效果。主菜单**卡牌图鉴 / 组牌**可编辑30张牌组，同名最多2张。
- **结束回合**切换玩家；结束后可**再来一局**。联机再战需双方准备。

完整的图片抄录、涂改处和采用值见 [图片文字与规则.md](图片文字与规则.md)。按用户后续要求新增开局换牌；手稿中模糊的每回合换牌描述没有实施。已有插画按卡名和效果独立设计，显示于开局换牌、手牌、场上单位、详情和图鉴；现有素材见 `assets/`，生成提示词文件当前尚未提供。

## 项目结构和验证

|文件|用途|
|---|---|
|`main.py`|游戏入口与错误记录|
|`empire_front/cards.py`|26张卡牌的数值和效果描述|
|`empire_front/engine.py`|与UI、网络分离的规则引擎|
|`empire_front/network.py`|TCP房间、隐藏手牌、断线重连|
|`empire_front/app.py`|Tkinter指挥台、训练AI、图鉴与组牌|
|`empire_front/tabletop.py`|复古地图桌面、纸质卡面和二次元插画加载|
|`assets/cards/`|目前提供的5张独立二次元插画|
|`tests/`|规则和真实TCP双端联机测试|
|`tools/build_release.py`|生成Windows EXE与源码压缩包|

```powershell
python -m unittest discover -v
python tools/gui_smoke.py
```

测试包括完整AI对战、战线容量、无效动作不扣资源、伤害与遗言、技能冷却、装弹、隐藏手牌、房间口令、席位冲突、状态同步、掉线暂停、重连、再战，以及开局任意数量换牌、返还旧牌、数量守恒、同时确认和整备阶段断线恢复。GUI测试会创建自己的测试窗口，然后自动关闭。

自行打包需要已安装PyInstaller，并先补齐全部26张插画以通过打包自检：

```powershell
python -m pip install pyinstaller
python tools/build_release.py
```

网络面向熟人局域网/VPN房间，没有传输加密或互联网匹配服务；房主进程持有完整状态。没有在线账号或运行时素材下载。地图与卡面由Python绘制，已有二次元插画包含在当前源码包中。当前源码双方须使用同一个1.1版本，旧版无法连接新版。
